# Systolic Array

既存コアの静的bank配置、同報、FIFO境界を、複数のPEが規則的にデータを受け渡すシストリックアレイへ接続する応用例です。

## コアとの対応

- laneをPE列またはPE行の入力ポートとして扱う。
- multicastで共通入力・係数・制御を複数PEへ配布する。
- bank schedulerでPE投入順と読み出し集合を静的に決める。
- FIFOで配列端の投入・排出とbackpressureを隔離する。

## 最初の題材

小さな行列積またはFIRタイルを対象にし、スカラ参照結果との一致、入力再利用回数、PE投入間隔を比較します。
一般的な行列積の性能や任意形状のアレイを、現時点では主張しません。

## 検証境界

これは応用提案です。既存コアのRTLは変更せず、adapterの参照モデルとRTLを追加して検証します。
資源数、配線遅延、クロック周波数、物理実装結果は別途測定するまで未検証です。
