# Applications

[日本語](README.md) · English · [简体中文](README.zh-Hans.md)

The canonical public records are three independent derived application repositories. This directory keeps short local snapshots and the common evidence index.

| Application | Canonical repository | Local snapshot |
|---|---|---|
| Precision Clock / Timer | [banked-precision-clock-multicast](https://github.com/HN19781124/banked-precision-clock-multicast) | [precision-clock](precision-clock/README.md) |
| Systolic Array | [banked-systolic-multicast](https://github.com/HN19781124/banked-systolic-multicast) | [systolic-array](systolic-array/README.md) |
| TDOA Sensor Array | [banked-tdoa-multicast](https://github.com/HN19781124/banked-tdoa-multicast) | [tdoa-sensor](tdoa-sensor/README.md) |

These records use reference models and reproducible tests; they do not change the core RTL or replace its verification evidence. The fixed combined metrics are in [evidence/three-application-performance.json](evidence/three-application-performance.json).
