# TDOA Sensor Array

TDOA（到来時刻差）計測へ同報コアを転用する応用例です。共通tickを複数センサへ配布し、各センサで記録した到着時刻の差から信号源の方向・位置を推定します。

## コアとの対応

- multicastをセンサlaneへの共通基準tick配布に使う。
- 各laneはセンサイベントと、粗いtick番号・細かい遅延値を記録する。
- 既知の配線遅延を校正値として差し引き、lane間の時刻差を得る。
- 幾何計算とセンサ固有の信号処理はcore外部のアプリケーション層に置く。

## 最初の題材

既知のイベント時刻とlaneごとの遅延を合成し、補正後のTDOAが基準値と一致するケースから始めます。
センサ雑音、反射、電波伝搬、衛星環境を含む成立性は、現時点では主張しません。

## 検証境界

これは応用提案です。遅延差、校正誤差、tick欠落、同時イベントを参照モデルで確認し、必要ならcapture adapterのRTLへ進みます。
時計の絶対精度や測位精度は、別の実測・試算として記録します。
